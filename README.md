# CodeAlpha Social Media Platform

A social media web application developed as part of the CodeAlpha Full Stack Development Internship.

## Features

- User profile section
- Follow and unfollow functionality
- Create and publish posts
- Like posts
- Comment on posts
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Overview

This project simulates a social media platform where users can create posts, interact through likes and comments, and engage with user profiles through follow functionality.

## Files

- `index.html` – Main application structure
- `style.css` – Styling and layout
- `script.js` – Interactive functionality
